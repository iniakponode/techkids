                    TELEGRAM BOT - SIMPLE GUIDE
═══════════════════════════════════════════════════════════════════════

Step 1: CREATE BOT ON TELEGRAM (Phone or Computer)
───────────────────────────────────────────────────────────────────────
   📱 Open Telegram
      ↓
   🔍 Search: @BotFather
      ↓
   💬 Send: /newbot
      ↓
   📝 Follow prompts
      ↓
   🎉 COPY YOUR TOKEN!
      Example: 7845123456:AABbCcDdEeFfGgHhIiJjKkLl

───────────────────────────────────────────────────────────────────────

Step 2: CREATE A CHANNEL (Phone or Computer)
───────────────────────────────────────────────────────────────────────
   📱 Telegram → New Channel
      ↓
   📝 Name it: "My Test Channel"
      ↓
   🔓 Make it Public
      ↓
   📝 Username: @my_test_channel
      ↓
   👤 Add your bot as Administrator
      ↓
   ✅ Give it "Post Messages" permission

───────────────────────────────────────────────────────────────────────

Step 3: ADD TO TECHKIDS (Web Browser)
───────────────────────────────────────────────────────────────────────
   🌐 Login to TechKids Admin
      ↓
   📊 Go to "Social Media Control Center"
      ↓
   👉 Find "Platform Credentials" box (right side)
      ↓
   📝 Fill in:
      
      Platform:      Telegram ▼
      Access Token:  7845123456:AABbCcDdEeFfGgHhIiJjKkLl
      Metadata:      {"channel_id": "@my_test_channel"}
      
      ↓
   💾 Click "Save Credentials"
      ↓
   ✅ DONE! Now you can post!

───────────────────────────────────────────────────────────────────────

Step 4: POST TO TELEGRAM (Web Browser)
───────────────────────────────────────────────────────────────────────
   📊 Still in "Social Media Control Center"
      ↓
   👉 Find "Create or Schedule a Post" box (left side)
      ↓
   📝 Fill in:
      
      Platform:      Telegram ▼
      Content Type:  Post ▼
      Content:       "Hello from TechKids! 🎉"
      Image:         [Optional] Upload a photo
      Schedule Time: [Optional] Pick a date/time
      
      ↓
   💾 Click "Save Post"
      ↓
   🎉 Check your Telegram channel - message posted!

┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│  What is...                                                         │
│                                                                     │
│  Bot Token?                                                         │
│  → Secret password from @BotFather                                  │
│  → Looks like: 1234567:ABCdefGHIjklMNO                            │
│  → Never share publicly!                                            │
│                                                                     │
│  Channel ID?                                                        │
│  → Your channel's @ username                                        │

│  → Must start with @                                                │
│                                                                     │
│  Metadata?                                                          │
│  → JSON format: {"channel_id": "@your_channel"}                    │
│  → Copy this exactly, just change the channel name                  │
│                                                                     │

                        ❌ COMMON MISTAKES

  ❌ Forgetting @ in channel ID
     Wrong: techkids_test
     Right: @techkids_test

  ❌ Wrong metadata format
     Wrong: @techkids_test
     Right: {"channel_id": "@techkids_test"}

  ❌ Not adding bot as channel admin
     → Bot can't post without admin permission!

  ❌ Sharing bot token publicly
     → Keep it secret! It's like a password!
